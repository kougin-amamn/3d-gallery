# 機械式時計 設計書

Nov 5, 2026 · @NG

## 1. コンセプト

**「裏蓋を開けた高級時計を、ルーペで覗き込む」体験を作る。** 開いた瞬間の現在時刻どおりに針と歯車が動き、てんぷが休まず往復します。ずっと眺めていられることを最優先にし、機能を盛るより一つひとつの部品の質感と動きの正確さを詰めます。

操作は「回して見る」「寄って細部を見る」「部品を分解して仕組みを見る」の3つに絞ります。

| チープに見える原因 | 設計上の対策 |
| --- | --- |
| 金属がプラスチックのように見える | スタジオ照明を写り込ませる環境マップ、素材ごとの粗さの差、仕上げ模様の細かな反射で質感を出す |
| 歯車がただの円盤に見える | 正確なインボリュート曲線の歯、スポーク(腕)の肉抜き、面取り、軸受けのルビーまで作る |
| 動きが一定で機械的すぎる | てんぷは等速ではなく振り子のように速さが変わる往復運動にし、ガンギ車は止まっては進む「刻み」を再現する |
| 部品の数が少なくスカスカ | 地板・受け・ネジ・ゼンマイ・ルビーを密に配置し、何層にも重なった奥行きを作る |
| すべてが均一に明るい | 照明は少数の強い光源にし、影と暗部を残す。寄ったときは手前と奥をぼかす |
| 全体像しか見られない | 脱進機やてんぷなど見せ場ごとに寄れるカメラ位置を用意する |

## 2. 機構の設計

**一般的な手巻きムーブメントと同じ構成で、歯数の比を正しく保って組みます。** てんぷは毎秒8振動(4Hz、毎時28,800振動)で、4番車が1分に1回転して秒針になります。歯数は特定の実在モデルではなく、この比を満たす設計値です。

| 部品 | 歯数 | かみ合う相手 | 回転の速さ | 役割 |
| --- | --- | --- | --- | --- |
| 香箱(ゼンマイの箱) | 80 | 2番かな 10 | 8時間で1回転 | 巻いたゼンマイの力を出す |
| 2番車(中心車) | 80 | 3番かな 10 | 1時間で1回転 | 分針。日の裏車にも力を渡す |
| 3番車 | 75 | 4番かな 10 | 7.5分で1回転 | 回転を速める中継ぎ |
| 4番車 | 80 | ガンギかな 5 | 1分で1回転 | 秒針 |
| ガンギ車 | 15 | アンクルの爺 | 1秒に4歯ずつ(毎分16回転) | 止まっては進む「刻み」を作る |
| アンクル | — | ガンギ車・てんぷ | 毎秒8回、左右に振れる | ガンギ車を止め、てんぷに力を足す |
| てんぷ | — | ひげゼンマイ | 4Hz、振れ幅 約270度 | 時間の基準(振り子) |
| 日の裏車・筒車 | 筒かな12→36、かな10→40 | 2番車の軸 | 12時間で1回転 | 時針(比 12:1) |

動きは「現在時刻から各部品の角度を計算する」方式にします。フレームごとに積み上げるとずれがたまるためです。ガンギ車と秒針は1/8秒ごとに進む段階的な動きで、てんぷはその間をつなぐ滑らかな往復です。

### 表側のための配置(決定)

**秒針は6時位置のスモールセコンド、ムーンフェイズは12時位置にします。** どちらも歯車の配置に関わるため、裏側を作る前に決めました。文字盤や針の形、ケースのデザインはあとから決められます。

| 部品 | 歯数・仕組み | 回転の速さ | 役割 |
| --- | --- | --- | --- |
| 4番車の位置 | 6時方向に置き、軸を文字盤側へ出す | 1分で1回転 | スモールセコンドの秒針 |
| 24時間車 | 筒車(12時間で1回転)から 1:2 で減速 | 24時間で1回転 | 1日に1回、ツメで月齢車を送る |
| 月齢車(ムーンフェイズ) | 59歯。月の絵を2つ描いた円盤 | 1日1歯(59日で1回転) | 29.5日で満ち欠けが一巡する |
| ジャンパーばね | 月齢車の歯を1歯ずつ止める板ばね | — | 月の絵がずれないよう押さえる |

月齢車の59歯は実物で一般的な方式で、約2年半で1日ずれます。そこで起動時に、太陽系ビューアと同じ月の計算から「今日の月齢」を求めて合わせます。毎日の送りは59歯の仕組みどおりに動かします。

## 3. 部品の作り方

**すべての部品をコードで生成し、寸法は `data/movement.json` にまとめます。** 歯数や位置を変えれば、別のムーブメントも組める作りにします。実寸(mm)で作り、直径約30mmのムーブメントを想定します。

| 部品 | 作り方 | 品質のポイント |
| --- | --- | --- |
| 歯車 | インボリュート曲線で歯の輪郭を計算し、押し出しで厚みを付ける | 歯先と角の面取り、4〜6本のスポーク、中心の円形の研磨模様 |
| かな(小歯車) | 歯車と同じ計算で歯数5〜12。軸と一体で作る | 銅色ではなく磨いた鋼の色。歯の形が細かいので分割数を多くする |
| ガンギ車 | スイスレバー式の独特な「足」の形(15歯) | 歯の先の斜面(衝撃面)を正確に作り、動くと光が走るようにする |
| アンクル | 平面形状を押し出し、赤い爺石(ルビー)2個を差し込む | 爺石は半透明の赤。光を透かす質感を出す |
| てんぷ | 円環と腕、周の調整ネジ。ひげゼンマイはアルキメデスの渦巻きを線で作る | 振れるとひげゼンマイが伸び縮みする(渦の間隔が変わる) |
| 香箱とゼンマイ | 円筒の箱。蓋を外すと渦巻きのゼンマイが見える | 巻き上げ量で渦の密度が変わる(将来の拡張) |
| 地板・受け | 輪郭をJSONの座標で定義し、穴を開けて押し出す | 縞模様(コート・ド・ジュネーブ)と粒状の模様(ペルージュ)、面取りした縁 |
| ネジ | 頭にマイナスの溝を彫った円筒 | 焼き入れの青。溝の向きを一本ずつ変える |
| 穴石(軸受け) | 軸の周りに置く赤いリング | 光が当たると内側が赤く輝く |

地板と受けには、歯車が見えるように大きな窓(肉抜き)を開けます。実物の「スケルトン時計」に近い見せ方です。

## 4. 素材と照明

**金属の質感は「何が写り込むか」で決まるため、スタジオの照明を模した環境マップを自作します。** 細長い白い光の帯(ソフトボックス)を暗い背景に数本置き、磨いた面にくっきりした反射が映るようにします。写真の環境画像は使わず、この光の配置は `data/lighting.json` で調整します。

| 素材 | 色 | 表面 | 使う部品 |
| --- | --- | --- | --- |
| ロジウムめっき | 白い銀色 | 縞模様、粒状模様。縁は鋭い面取り | 地板・受け |
| 金めっき | やや赤みのある金 | 円形の研磨模様 | 歯車(主役の色) |
| 磨いた鋼 | 冷たい灰色 | 鏡面に近い | かな、軸、ガンギ車、アンクル |
| 焼き入れネジ | 深い青 | 鏡面 | ネジ、ひげゼンマイの一部 |
| ルビー | 半透明の赤 | 内側から光るような透過 | 穴石、爺石 |

- **仕上げの反射:** 縞模様や円形の研磨は、模様に沿って光が伸びる「異方性の反射」で表現します(Three.js の MeshPhysicalMaterial の anisotropy)。光を動かすと模様が浮かび上がります。
- **影と暗さ:** 部品が重なる所には影を落とし、歯車の間の暗部で奥行きを出します。接地影(AO)も足します。
- **照明の強さ:** 強い主光源と1〜2本の弱い補助光だけにし、均一に明るくしません。
- **背景:** 定番の「黒いベルベットの上に置いた時計」。彩度の低い暖かい黒で、金と銀を引き立てます。

## 5. 動き・カメラ・UI

**見せ場は「てんぷと脱進機」「歯車の連なり」「分解」の3つです。** それぞれに寄れるカメラ位置を用意し、太陽系ビューアと同じく弧を描いて滑らかに移動します。

- **脱進機の動き:** てんぷが中心を通る瞬間にアンクルを弾き、アンクルがガンギ車を半歯だけ進めて止める。この順番を角度の計算で正確に再現します。
- **てんぷ:** 振り子と同じく、端で止まり中央で最も速い往復。ひげゼンマイが合わせて伸び縮みします。
- **スローモーション:** 4Hzは速すぎて目で追えないため、実速・1/4・1/16の速さを切り替えられるようにします。実速のときは針が現在時刻を指します。
- **分解(展開図):** ボタンひとつで受けや歯車を縦に浮かび上がらせ、部品の重なりを見せます。動きは止めずに回り続けます。
- **部品の名前:** 部品に触れると名前と役割を小さく表示します(例: 「ガンギ車　15歯　毎分16回転」)。
- **音(任意):** ガンギ車が止まるたびの「チッ」という音。タップで音を出し、実速では毎秒8回鳴ります。
- **操作バー:** 見せ場の切替、速さ、分解、表側(文字盤)と裏側の切替、音、画質。何もしないと薄くなります。

**表側(M5):** 文字盤、針、サファイアガラス、ケースを作り、裏側と切り替えて見られるようにします。12時の小窓に今日の月が見え、6時の小窓で秒針が回ります。裏側からは、24時間車のツメが1日に1回、月齢車を1歯送る様子が見えます。時刻を早送りすると、この送りの動きを確かめられます。

## 6. 技術とソース管理

**太陽系ビューアと同じく Three.js r170 を同梱し、ビルドなしで動かします。** 3d-gallery の `clock/` フォルダに置き、`data/works.json` に1件足して一覧に出します。

```text
clock/
├─ index.html
├─ src/
│  ├─ main.js              初期化とメインループ
│  ├─ core/                camera(見せ場への移動), quality, loader
│  ├─ mech/                gear(歯の形), train(輪列の角度計算), escapement, balance
│  ├─ parts/               plates, bridges, screws, jewels, hands, dial
│  ├─ look/                materials(素材と仕上げ), studio(照明と環境マップ)
│  ├─ post/                ブルーム、被写界深度、接地影
│  └─ ui/                  hud, labels
├─ data/
│  ├─ movement.json        歯数・位置・寸法・地板の輪郭
│  ├─ materials.json       素材の色・粗さ・仕上げ
│  ├─ lighting.json        スタジオの光の配置
│  ├─ views.json           見せ場のカメラ位置と説明
│  └─ quality.json
├─ tools/test-train.mjs     歯数の比と針の時刻を確かめるテスト
└─ vendor/three/
```

- **計算の分離:** `mech/` は描画に依存しない関数にし、「12時30分のとき分針が180度」のような確認をNodeで自動化します。
- **歯のかみ合い:** 隣り合う歯車の初期角を自動で合わせ、歯が食い込まないようにします。軸間の距離は歯数と大きさ(モジュール)から計算します。
- **Git運用:** 3d-gallery リポジトリで管理し、マイルストーンごとに `main` へpushして公開ページに反映します。

## 7. 品質向上のための追加提案

**最も効果が大きいのは、最初に「てんぷと脱進機だけ」を写真のように仕上げることです。** ここは時計好きが最初に見る部分で、質感と動きのどちらが欠けても「作り物」に見えます。

1. **垂直スライスを先に作る:** てんぷ・アンクル・ガンギ車・受け1枚だけで、金属の質感と動きを仕上げます。納得できなければ、全体を作る前に方針を見直します。
2. **実物の写真と並べる:** 裏蓋がシースルーの時計の写真を参照にし、反射の強さと色を合わせます。参照は自分用で、画面には使いません。
3. **動きをテストする:** 歯の食い込みや、ガンギ車とアンクルの位置のずれを自動で検出します。歯車がすり抜けて見えると一気にチープになるためです。
4. **寄ったときの解像感:** 近づいた部品だけ分割数を上げ、歯の角がカクカクしないようにします。被写界深度で「マクロ撮影」の印象を出します。
5. **スクリーンショットで前後比較する:** 全体・脱進機・分解の3つの定点を決め、変更ごとに同じ画を比べます。
6. **表側も作る(任意):** 文字盤と針、サファイアガラスの反射。裏側と切り替えて、普通の腕時計としても眺められます。
7. **改良の余地を残す:** 将来はトゥールビヨン(脱進機ごと回る機構)やムーンフェイズを `movement.json` の追加で足せる構造にします。

## 変更履歴(設計書の公開後に決めたこと)

### 配置の見直し(M2、2026-11-05)

- 2番車を地板の中心に置くため、脱進機まわり以外の配置を作り直した。部品どうしがぶつからない位置を `tools/layout.py` で探索
- 輪列: 香箱(80歯、モジュール0.15)→ 2番かな(10)、2番車(80)→ 3番かな(10)、3番車(75)→ 4番かな(10)、4番車(80)→ ガンギかな(5)
- 4番車が6時位置に来るよう全体を回転(小秒針を6時に置くため)

### 見せ方(M3)

- 分解表示: 部品ごとに段を持たせて持ち上げる。上の段ほど少し遅れて動き出す
- 部品の名札と説明(`data/parts.json`)、部品をクリックしても説明が出る
- 視点: 脱進機・てんぷ・巻き上げ・ムーブメント

### 腕時計への仕立て(M5、2026-11-06)

- 40mmのステンレスケース、ドーム型サファイア、シースルー裏蓋、リューズ(表から3時)、茶色の革ベルトと尾錠
- 表裏の切り替え: 回転軸は12時と6時のバネ棒を結ぶ線。ベルトは回らない側に置き、回すあいだは時計全体を少し持ち上げる
- 文字盤: 銀のオパーリン、ローマ数字(Ⅵは小秒針のため省く)、青焼きのブレゲ針
- **12時はデイナイト表示**(当初の設計ではムーンフェイズ): 1日1回転の円盤。朝6時に太陽が左から昇り、正午に窓の中央、夕方6時に右へ沈む。夜は星空と三日月
- **ムーンフェイズは6時の小秒針の中へ移動**: 2つの月で1朔望月に半回転。新月で左の丘の下、満月で窓の中央(右側から光る=北半球の見え方)
- ガラスは写り込みだけの薄い透明にし、被写界深度の奥行きには入れない

### 裏側の受けの作り直し(2026-11-06)

- 細い受けが点在して隙間だらけに見えたため、地板をほぼ覆う大きな受け3枚(香箱受け・輪列受け・4番受け)に変更
- てんぷと脱進機の部分だけ窓を開ける。窓を除いた円を軸の位置で分け、境目に細い溝を入れる(`movement.json` の `partition`)
- ガンギ受けとアンクル受けは窓の上に架かる小さな受けに。2・3・4番車の穴石は金の座金と青ネジで留める
- コート・ド・ジュネーブは縞を太く、明暗を穏やかに
