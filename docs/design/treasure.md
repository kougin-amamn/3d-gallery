# 宝箱 設計書

3d-gallery の作品として、「リアルでポップな宝箱」を3Dで作る(フォルダは `treasure/`)。

## コンセプト

**「ご褒美の瞬間」。** 触りたくなる形と色はポップに、手で触れたときの質感はリアルにする。

| | ポップに振るところ | リアルに振るところ |
|---|---|---|
| 形 | 少しずんぐりした比率、太めの金具、大きめの鋲、丸みのある角 | 板を1枚ずつ組んだ構造、板の間のすき間、角の面取り |
| 色 | はちみつ色の木、金の金具、赤い内張り、色の強い宝石、パステルの背景 | 板ごとの色むら、木目、金具の磨き跡と擦れ |
| 動き | 待機中に「開けて」と跳ねる、フタのばね、飛び出す金貨 | 重力、床で跳ねて止まる金貨、柔らかい接地影 |

参考画像(錆びた鉄帯の木箱)の構造(かまぼこ形のフタ、帯金、鋲、南京錠、横の取っ手)はそのまま受け継ぎ、錆びた鉄だけを磨いた真鍮の金色に置き換えてポップにする。

## 色

| 用途 | 色 | 理由 |
|---|---|---|
| 木 | #C8772F〜#9A5223(はちみつ〜キャラメル) | 暖かく明るい。金と並べても沈まない |
| 帯金・角金・取っ手 | #E9C27A(古びた金) | くすみと槌目で重みを出す |
| 鋲・錠前・金貨 | #F6D894(磨いた金) | 帯金より明るく、視線を集める |
| 内張り | #C8243A(深紅のベルベット) | 金貨の金を引き立てる補色寄りの赤 |
| 宝石 | 赤 #FF3B5C、青 #3BA0FF、緑 #32D27A、紫 #A65BFF | ポップの差し色 |
| 背景 | #BFE3F2 → #F4D9EC(空色から薄いピンク) | 明るく軽い。主役の暖色が浮く |
| 台 | #FFF3E2(クリーム) | 影が柔らかく見える |

色、寸法、動きの値は `data/chest.json` と `data/scene.json` に置き、コードに埋め込まない。

## 構造(単位はメートル、箱の幅 1.0)

- **胴:** 幅 1.0、奥行 0.66、高さ 0.5。前後と左右の壁は横長の板3枚ずつ。厚み 0.05。底板あり。
- **フタ:** 半径 0.33 の半円柱を、6枚の板(樽板)で組む。両端は半円の板。
- **金具:** 胴とフタをまたぐ縦の帯金2本、胴の上下の縁帯、四隅の角金、フタ両端の半円の縁帯。
- **鋲:** 帯金に沿って一定間隔に並べる(インスタンス描画)。
- **錠前:** フタから垂れる掛け金と、金の南京錠。鍵穴は黒、上に小さな赤い宝石。
- **取っ手:** 左右の側面に金の半輪。
- **中身:** 赤い内張りと、こんもり積んだ金貨の山、宝石いくつか。

形はすべてコードで作る(角の丸い押し出し形状)。外部の3Dモデルは使わない。

## 質感

- **木目:** 起動時にキャンバスで木目の色・凹凸・粗さのテクスチャを作る。板ごとに位置をずらし、色を少し変えて「同じ木目の板が並ぶ」不自然さを消す。
- **金:** 金は「何が映り込むか」でほぼ見た目が決まる。明るい背景をそのまま映すと全面が同じ黄色になり、塗装のように安っぽく見える。そこで次の4つで本物らしさを出す。
  - **金属専用の映り込み:** 金属と宝石だけ、暗い部屋に強い光の板を並べたスタジオを映す(`scene.json` の `metalEnv`)。暗い面と鋭い光が同時に映り、深い金色と明るいハイライトの差が生まれる。背景のパステルは映さない。
  - **本物の金の色:** オレンジ寄りの黄色ではなく、淡い金(#F6D894 前後)を素材の色にする。濃い色は暗い部分の映り込みで自然に出る。
  - **むら:** 色にくすみ(くぼみや雲状の部分が茶色く暗い)、粗さに一方向の磨き傷、法線に槌目(ハンマーで打った浅いくぼみ)を入れる。起動時に生成(`wood.js` の `goldTextures`)。
  - **格の差:** 帯金などの大きな面は古びた金(くすみ多め、`metal.aged`)、鋲・錠前・ちょうつがい・金貨は磨いた金(`metal.polished`)。
- **金貨:** 表面に王冠と粒の輪の浮き彫り(法線マップ)。
- **宝石:** ブリリアントカット風の多面体。金属と同じ暗いスタジオを映し、面ごとの明暗できらめかせる。
- **影:** 主光源の柔らかい影と、台への接地影。

## 動き

1. **待機:** 数秒おきに小さく跳ねる(つぶれて、伸びて、着地でまたつぶれる)。鍵穴の宝石がきらっと光る。
2. **タップ:** 錠前が外れて跳ね落ちる → フタがばねのように勢いよく開き、少し行き過ぎて戻る → 中から光があふれ、金貨と宝石が弧を描いて飛び出し、台の上で跳ねて止まる。
3. **もう一度タップ:** 散らばった金貨が小さくなって消え、フタが閉じ、錠が戻る。

ドラッグで視点を回し、ホイールやピンチで拡大できる。

## 構成

Three.js r170 を同梱し、ビルドなしで ES モジュールと importmap で動かす(3d-gallery の作品と同じ方式)。https 配信が前提。

```
treasure/
├─ index.html
├─ data/
│  ├─ chest.json      寸法・色・鋲の間隔・動きの値
│  └─ scene.json      背景・光・カメラ・画質
├─ src/
│  ├─ main.js         読み込み・描画ループ・操作
│  ├─ chest/          箱の形(build.js)、木目・金・刻印のテクスチャ(wood.js)、形の道具(shapes.js)
│  ├─ fx/             金貨と宝石(treasure.js)
│  ├─ look/           スタジオ照明と環境マップ(studio.js)
│  └─ ui/style.css
└─ vendor/three/
```

## 変更履歴

- **v0.1 プレビュー:** 最初の形。金具はすべて同じ黄色の金で、背景の明るい部屋を映していた。
- **v0.1(3d-gallery に追加):** 「安っぽい、特に金」という指摘を受けて、金を作り直した(上の「質感」の **金** の項)。あわせて、後ろの縁をちょうつがいに変え、錠前を1.25倍にし、フタの板の角の陰、宝石の色の濃さ、金貨の刻印を足した。置き場所は 3d-gallery の `treasure/` に決定。
