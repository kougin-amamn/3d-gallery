# 宝箱 設計書

3d-gallery の作品として、宝箱を3Dで作る(フォルダは `treasure/`)。

**v0.2 からの方針: 形はシンプル、材質と光はリアル(セミリアルのゲームアセット)。** 軽さは保ったまま、木と鉄が自然で上質に見えることを最優先する。

## コンセプト

**「ご褒美の瞬間」。** 形と動き(ずんぐりした比率、跳ねる待機、ばねのフタ、飛び出す金貨)は遊び心を残し、木と鉄の質感と光はリアルにする。

参考画像(鉄帯の木箱)の構造(かまぼこ形のフタ、帯金、鋲、南京錠、横の取っ手)を受け継ぐ。金具は v0.1 では金色だったが、v0.2 で参考画像と同じ黒い鉄に戻した。金は中身の金貨だけに使い、「宝」の色として際立たせる。

## 色

| 用途 | 色 | 理由 |
|---|---|---|
| 木 | #6E4D33(地)、#3C2616(濃い筋)、#8F6A4A(淡い筋) | 落ち着いた中〜濃茶色。オレンジに寄せない |
| 帯金・角金・取っ手 | #696C71(打ち出しの黒い鉄) | 暗いグレー。角は擦れて明るい |
| 鋲・錠前・ちょうつがい | #74777C(少しなめらかな鉄) | 帯金と同じ鉄で、粗さだけ低い |
| 金貨 | #F6D894(磨いた金) | 箱の中で唯一の金。視線を集める |
| 内張り | #C8243A(深紅のベルベット) | 金貨の金を引き立てる補色寄りの赤 |
| 宝石 | 赤 #E8103A、青 #1E6BFF、緑 #10B85A、紫 #8A2BE2、橙 #FF9800 | 差し色 |
| 背景 | #BFE3F2 → #F4D9EC(空色から薄いピンク) | 明るく軽い。主役の暖色が浮く |
| 台 | #BFEBDD(ミント) | 茶色の木の補色寄り。影が柔らかく見える |

色、寸法、動きの値は `data/chest.json` と `data/scene.json` に置き、コードに埋め込まない。

## 構造(単位はメートル、箱の幅 1.0)

- **胴:** 幅 1.0、奥行 0.66、高さ 0.5。前後と左右の壁は横長の板3枚ずつ。厚み 0.05。底板あり。
- **フタ:** 半径 0.33 の半円柱を、6枚の板(樽板)で組む。両端は半円の板。
- **金具:** 胴とフタをまたぐ縦の帯金2本、胴の上下の縁帯、四隅の角金、フタ両端の半円の縁帯。
- **鋲:** 帯金に沿って一定間隔に並べる(インスタンス描画)。
- **錠前:** フタから垂れる掛け金と、鉄の南京錠。鍵穴は黒、上に小さな赤い宝石。
- **ちょうつがい:** 後ろに2つ。
- **取っ手:** 左右の側面に鉄の半輪。
- **中身:** 赤い内張りと、こんもり積んだ金貨の山、宝石いくつか。

形はすべてコードで作る(角の丸い押し出し形状)。外部の3Dモデルは使わない。

## 質感

### 木(最優先)

木が安っぽく見えた原因は、(1) 彩度の高いオレンジ、(2) 粗さ 0.55〜0.8 のつや、(3) 強い法線マップのぬめった凹凸、(4) 年輪の等高線を波打たせた漫画的な模様、の4つだった。

- **素材:** `MeshStandardMaterial`、金属度 0、粗さ 0.8〜0.95(鏡面反射を持たせない)。凹凸は `bumpMap` で控えめに(`wood.bumpScale`)。
- **木目:** `CanvasTexture` で起動時に描く(1024×512、横が板の長手方向)。年輪の等高線ではなく、長手方向に流れる細い筋の集まりで描く(柾目〜追柾)。
  - 筋は1本ずつ間隔・太さ・濃さ・うねりを変える。濃い晩材の筋は少なめ、ごく細い筋を多めにして、規則的な縞に見せない。
  - 幅の広い色の帯、長手方向に伸びた濃淡、短い道管のくぼみ、節を少し重ねる。
  - 上下・左右とも継ぎ目なくつながる(繰り返して貼っても目立たない)。
  - 色の1枚と、灰色の1枚(凹凸と粗さを兼用。`bumpMap` は R、`roughnessMap` は G を読む)の2枚だけ。
- **板ごとの違い:** 木目の位置(位相)、筋の間隔(UV の縦の倍率 0.75〜1.3)、色(頂点色で ±数%)を板ごとに変える。テクスチャは全板で共有する。
- **陰影(頂点色):** 板の面取りは暗く(すき間が深く見える)、箱の内側の面は暗く、木口(切り口)は暗く。木口は実物でも繊維の穴が光を吸って暗い。
- **形:** 板は厚み 5cm、角は 8mm の面取り。板の間に 6mm のすき間。

### 鉄

- **素材:** `MeshStandardMaterial`、金属度 0.9、粗さ 0.45〜0.75(鋲・錠前は 0.35〜0.55)。地の色は暗いグレー。
- **むら:** 色にくすみ(黒ずみ)、粗さに磨き傷、法線に浅い槌目。起動時に生成(`wood.js` の `goldTextures` を鉄の値で使う)。
- **角の擦れ:** 帯金の面取り部分の頂点色を明るくして、角だけ地金が光るようにする(`metal.edgeWear`)。
- **映り込み:** 金属と宝石だけ、暗い部屋に光の板を並べた簡易環境マップを映す(`scene.json` の `metalEnv`)。背景の明るいパステルを映すと、金属がプラスチックのように平板になる。

### 金貨・宝石

- **金貨:** 磨いた金。表面に王冠と粒の輪の浮き彫り(法線マップ)。
- **宝石:** ブリリアントカット風の多面体。金属と同じ暗いスタジオを映し、面ごとの明暗できらめかせる。

### 光と影

- 既存の照明(斜め上の主光源、弱い補助光、HemisphereLight、背景の環境光)をそのまま使い、強さだけ調整した。環境光を 1.0 → 0.7 に下げ、主光源を 2.3 → 2.7 に上げて、面ごとの明暗(形の立体感)が出るようにした。宝箱専用の光は足していない。
- 影は主光源の1つだけ。何かが動いたとき(跳ねる、フタ、錠前、金貨)だけ影を描き直し、止まっている間は前の影を使う。
- スマホなどの軽い画質では、影の方式を PCF(ぼかしの軽いもの)にする。

## 描画負荷

| | v0.1 | v0.2 |
|---|---|---|
| 閉じた状態の三角形数(影の描き直しを含む) | 約 647,000 | 約 51,000 |
| 閉じた状態の三角形数(止まっている間) | 約 647,000 | 約 33,000 |
| 閉じた状態の描画回数(影を含む / 止まっている間) | 88 / 88 | 56 / 38 |
| テクスチャ数 | 33 | 29 |

主な削減は次のとおり。

- 金貨の分割を減らした(1枚 880 → 308 三角形)。箱の中の金貨の山は、フタが開いている間だけ描く。飛び出す金貨と宝石は、出ている間だけ描く。
- 箱の中の金貨の山と鋲は影を落とさない(見えない影を描かない)。鋲の分割も減らした。
- 影は動いたときだけ描き直す。
- ページを離れるときに、作ったテクスチャ・素材・形を解放する。

## 動き

1. **待機:** 数秒おきに小さく跳ねる(つぶれて、伸びて、着地でまたつぶれる)。鍵穴の宝石がきらっと光る。
2. **タップ:** 錠前が外れて跳ね落ちる → フタがばねのように勢いよく開き、少し行き過ぎて戻る → 中から光があふれ、金貨と宝石が弧を描いて飛び出し、台の上で跳ねて止まる。
3. **もう一度タップ:** 散らばった金貨が小さくなって消え、フタが閉じ、錠が戻る。

ドラッグで視点を回し、ホイールやピンチで拡大できる。

## 構成

Three.js r170 を同梱し、ビルドなしで ES モジュールと importmap で動かす(3d-gallery の作品と同じ方式)。https 配信が前提。

```
treasure/
├─ index.html
├─ data/
│  ├─ chest.json      寸法・色・鋲の間隔・動きの値
│  └─ scene.json      背景・光・カメラ・画質
├─ src/
│  ├─ main.js         読み込み・描画ループ・操作
│  ├─ chest/          箱の形(build.js)、木目・金・刻印のテクスチャ(wood.js)、形の道具(shapes.js)
│  ├─ fx/             金貨と宝石(treasure.js)
│  ├─ look/           スタジオ照明と環境マップ(studio.js)
│  └─ ui/style.css
└─ vendor/three/
```

## 改善候補(今回の品質改善とは別)

- 宝石を光が透ける素材(transmission)にする。高画質のときだけ。
- 金貨と錠前の当たり判定(今は重なることがある)。
- 木の内側の面にだけ、少し粗い木目(製材のままの面)を使う。
- 開けたときの音。

## 変更履歴

- **v0.1 プレビュー:** 最初の形。金具はすべて同じ黄色の金で、背景の明るい部屋を映していた。
- **v0.1(3d-gallery に追加):** 「安っぽい、特に金」という指摘を受けて、金を作り直した(上の「質感」の **金** の項)。あわせて、後ろの縁をちょうつがいに変え、錠前を1.25倍にし、フタの板の角の陰、宝石の色の濃さ、金貨の刻印を足した。置き場所は 3d-gallery の `treasure/` に決定。
- **v0.2(品質改善):** 依頼書「3D宝箱の品質改善」に沿って、形はシンプル・材質と光はリアルに方針を変えた。木目を CanvasTexture で描き直し(柾目の筋、板ごとの位相・間隔・色、木口と板のすき間の陰影、粗さ 0.8〜0.95、bumpMap)、金具を金から黒い鉄に戻した(角の擦れ、粗さ 0.45〜0.75)。照明は既存のものの強さだけ調整。描画負荷を下げた(上の「描画負荷」)。開閉と跳ねる動きは変えていない。
