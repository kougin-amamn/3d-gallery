# 機械式時計 v0.2

手巻きの腕時計を、表と裏から見る3D作品です。今の時刻に合わせて針・てんぷ・脱進機・輪列が動き、12時のムーンフェイズは今日の月齢に合わせて満ち欠けします。

## 構成

```text
index.html
data/
  movement.json   部品の配置・歯数・寸法(mm)
  materials.json  素材(色・粗さ・異方性反射)
  lighting.json   スタジオの光(写り込む光の板)
  views.json      視点・速さ・画質の段階
  parts.json      部品の名前と説明(分解表示の名札)
  watch.json      ケース・文字盤・針・ベルトの寸法と印刷する文字
src/
  mech/train.js   時刻から各部品の角度を計算(描画に依存しない)
  mech/gear.js    歯車・受けの平面形状
  parts/movement.js  ムーブメントの組み立てと分解表示
  parts/watch.js     ケース・ガラス・文字盤・針・ムーンフェイズ・革ベルト
  look/           仕上げ模様・素材・スタジオ照明
  main.js         画面・操作・後処理
tools/
  test-train.mjs  歯車の比と針の角度のテスト(node tools/test-train.mjs)
  layout.py       部品どうしがぶつからない配置の探索
vendor/three/     three.js r170
```

## 操作

- ドラッグで回転、ホイールで拡大
- F: 表裏を返す、5: 文字盤、6: ムーンフェイズ、1〜4: 脱進機 / てんぷ / 巻き上げ / ムーブメント、E: 分解、スペース: 一時停止
- 部品(または分解時の名札)をクリックすると説明が出ます

## 確認用の URL パラメーター

`?t=43210&pause` 時刻を固定、`?view=balance` 視点、`?q=low|medium|high` 画質、`?explode` 分解した状態で開く、`?view=dial|moon|seconds|caseback` 表裏の視点

## しくみのメモ

- 表裏の回転軸は12時と6時のバネ棒を結ぶ線。ベルトは回らない側にあり、回すあいだは時計全体を少し持ち上げます
- 月の円盤は2つの月で1朔望月に半回転。新月で左の丘の下、満月で窓の中央に来ます
- ガラスは写り込みだけの薄い透明で、被写界深度の奥行きには入れていません
- 裏側の大きな受け(香箱受け・輪列受け・4番受け)は、てんぷと脱進機の窓を除いた円を軸の位置で分けて作ります(movement.json の partition)。境目には細い溝が入ります
